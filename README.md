# Air Quality Insights

Streamlit city comparison for AQI and pollutant time series. The included data is fictional and must not be interpreted as an environmental measurement or health recommendation.

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Schema is documented in [DATA_DICTIONARY.md](docs/DATA_DICTIONARY.md).
